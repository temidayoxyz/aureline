# Aureline

Botanical skincare from Provence. A luxury brand website built with Vite.

## Concept

Aureline is a fictional boutique skincare brand based in Aix-en-Provence, France. The brand philosophy centers on radical ingredient transparency — every formula is named, numbered, and fully disclosed.

## Design Direction

- **Visual style**: Warm editorial minimalism
- **Typography**: Cormorant Garamond (serif) + DM Sans (sans-serif)
- **Palette**: Warm ivory, cream, terracotta accent
- **Imagery**: None — pure typography and botanical line illustrations
- **Motion**: Subtle scroll reveals
- **Architecture**: One-page brand statement

## Stack

- Vite
- Vanilla HTML/CSS/JS
- Google Fonts
